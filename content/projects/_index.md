这里展示我的开源项目，更多内容见 [GitHub 主页](https://github.com/huonanwholovecomputer)。

## 项目列表

| 项目 | 简介 |
|---|---|
| [HN Space（本站）](https://github.com/huonanwholovecomputer/hn-space-site) | 本站点源码，Hugo + PaperMod 深度定制，含液态背景、三态主题切换等自研效果。 |
| [h_n-printer](https://github.com/huonanwholovecomputer/h_n-printer) | 全栈项目，全自动打印PDF、Word和图片类型的文件，拥有订单和用户管理系统、支持小程序和APP远程发起打印任务，但没有提供微信支付功能，订单数据仅作为统计和数据展示。 |
| [campus-bandwidth-aggregation](https://github.com/huonanwholovecomputer/campus-bandwidth-aggregation) | 校园网「多设备并发会话」带宽合并的通用原理研究归档：无感认证 / 设备白名单 / 多会话并存模型、等效带宽验证方法论与健壮性设计。所有配置模板均占位符化，不含任何真实环境标识。 |
| [FrameKeeper](https://github.com/huonanwholovecomputer/FrameKeeper) | 一款在系统托盘中运行的 Windows 截图工具，可按固定间隔自动捕捉屏幕，并将图像序列轻松导出为延时视频。适合用于工作记录、项目监控与创意分享。使用多线程和生产者-消费者模型高速处理图片并将其合成为 MP4 视频、动态计算最佳视频码率。 |
| [auto_input_anywhere](https://github.com/huonanwholovecomputer/auto_input_anywhere) | 键盘输入助手：调用 Windows SendInput 的 Unicode 模式把文本逐字「敲」进当前焦点输入框，用于网页表单、聊天窗口、远程桌面、虚拟机等禁止粘贴的场景。不经过输入法（无需切换中英文、没有选词同音词问题）、不占用剪贴板，仅依赖 Python 标准库，附 PyInstaller 打包配置。 |
| [cpp_format](https://github.com/huonanwholovecomputer/cpp_format) | 格式化 C++ 代码的 Python 脚本。 |
| [Countdown-to-College-Entrance-Examination](https://github.com/huonanwholovecomputer/Countdown-to-College-Entrance-Examination) | 一款基于tkinter的简易桌面高考倒计时工具，提供了14种时间格式。 |
| [Python-Random-Select](https://github.com/huonanwholovecomputer/Python-Random-Select) | 一款在终端运行的学生名字随机抽取工具，学生名单在程序外部储存，名单使用Fernet进行加密，支持多种命令进行名单操作。 |
| [UTF-8-automatic-conversion](https://github.com/huonanwholovecomputer/UTF-8-automatic-conversion) | 批量转换文件编码的 Python 脚本，使用 chardet 自动识别 GBK 等编码，将指定文件或目录下指定类型的文件统一转换为 UTF-8，解决不同 IDE 间文件编码不一致导致的中文乱码问题。 |
| [Audio-Cover-Extraction-Tool](https://github.com/huonanwholovecomputer/Audio-Cover-Extraction-Tool) | 音频封面提取工具，自动提取程序所在目录的所有mp3文件的封面。 |

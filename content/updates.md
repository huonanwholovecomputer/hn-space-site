## 2026-09-11

- 卡片光效优化：手电筒光斑改为即时跟随指针（快速划过多个卡片不再从卡片中心追踪），并新增「边缘渐变高亮」——光斑照到卡片边缘时点亮边框，且只在鼠标指向的那张卡片上生效，不再跨卡片
- 卡片动效平滑：3D 倾斜改用两级低通滤波，快速拂过更顺、突变被抹去；上浮与回弹单独调速（上升 400ms、回弹 900ms）
- 主题切换重做：浅/深色切换改为整页合成层交叉淡入（View Transitions API），动画不再逐元素重绘，元素再多也不掉帧；顺带修复内容列与背景的色差竖条、以及文字比背景晚结束的问题；不支持该 API 的浏览器自动降级

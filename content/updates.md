## 2026-09-30

- **动效升级（分三批落地）**：以 MUUUUU 的 161 个「动态感强」案例为参考，挑出适合本站的做了一轮系统升级
  - 第一批（纯 CSS 优先）：标题逐行遮罩上推、强调短线绘制、按钮与链接的微交互反馈；文章阅读进度条、目录滚动高亮、正文图片遮罩揭示、文章标题逐行
  - 第二批（结构级）：首屏滚动纵深、颗粒纹理层、技术栈跑马灯；PJAX 换页过渡与慢网加载细线、数字滚动计数
  - 第三批（结构性）：引入 **Lenis 平滑滚动**（本地托管，开启「减少动态」时自动退回原生滚动）、文章左侧常驻目录栏、首页轻量开场
  - 修复：换页后滚动上界未及时刷新，导致「卡在顶部滑不动 + 每次滑动弹回顶部 + 画面闪烁」
- **标题尺度实验**：四个标题角色同步放大（首屏 53.6 → 80px、段落标题 30.4 → 44px、文章标题 38.4 → 48px、页头 32 → 40px），左下角面板可一键切回基准尺度（`?typescale=1`）；鼠标反色光圈与「霍楠 / h_n」窥视窗口按同一比例联动
- **关于页新增证书原件**：竞赛卡片里一个「查看获奖证书」按钮，点开是可左右切换的画廊（带说明与计数器，支持 ←/→ 翻看）；证书编号已隐去
- **关于页移除「常用软件」板块**
- **图片查看器交互修复**：图片为初始尺寸时，点击或拖动图片不再误关闭查看器；缩小时图片不会跑出画面；点击或拖动图片**外**的区域，在任意缩放状态下都能关闭；放大看图时背景不再跟着滚轮滚动
- **灯箱按钮重做**：`‹ › ×` 由文字字形改为内联图标（几何居中，不再因字体基线偏移而显得偏下）；雪佛龙另做视觉修正（`‹` 左移 1px、`›` 右移 1px），并修掉聚焦时圆形按钮被改成圆角方块的问题
- **首屏加载修复**：入场动画补上「首帧预隐藏」，内容不再先闪一下再被遮住；首帧底色改为主题实色，消除「先灰后黑」的跳变
- **修复「页面偶发卡在顶部滑不动」**：根因是静态脚本的缓存版本号长期没有更新，浏览器一直用着旧文件（该修的那次改动没能送达）；现在脚本地址随文件内容自动变化，改了什么就必然重新下载。同时给平滑滚动加了两道防御：非法的滚动目标会被拦下并归零，且一旦内部状态被写坏，下一次滚轮会自动复位——即使再遇到坏状态也不需要刷新页面。若检测到有外部脚本（浏览器扩展等）在**持续**往里写坏值，则自动退回浏览器原生滚动，绝不让页面卡住
- 内容索引：教程与开源项目两段由连续卡片栅格改为「编号 + 标题 + 摘要 + 时长」的行式索引，降低重复感
- 首页开源项目卡片维持大卡片形态（试过全宽出血带，观感违和已回退）；液态背景向下延伸一段，与下方段落衔接更自然
- **修复一个很隐蔽的滚动故障：访问过搜索页之后，鼠标滚轮会卡死在顶部**（触控滑动仍正常，所以第一眼像"鼠标坏了"）。原因是平滑滚动引擎的内部状态被写坏，且**它的实例会在整个会话里跨页面复用**，于是一次抖动被带到了之后每一页；滚轮归它接管、触控不归它管，这才出现"能滑/不能滑"的分裂现象。修复分两层：搜索页**不再持有**滚动引擎（离开时重建全新实例，切断跨页传播）；另外给它加了看门人——一旦发现内部状态被写坏，立即退回浏览器原生滚动并掐断它的滚轮接管，宁可少一层缓动也不让页面卡住

## 2026-09-29

- 上线**公开统计页**：新增 `/stats/` 页面，展示浏览量、访客数、会话数、跳出率与平均停留，以及访问趋势和热门页面、来源、地区、浏览器、设备、自定义事件六个维度；支持近 7／30／90 天切换，页脚新增「站点统计」入口
- 文章页新增**本文浏览量**：标题下方信息行显示该文章被浏览的次数（带 10 分钟缓存，来回翻页不重复请求接口）
- **访问统计全面升级**：
  - 采集 Web Vitals 真实性能指标（TTFB / FCP / LCP / CLS / INP），可查每篇文章的实际加载速度
  - 新增 7 类自定义事件：外链点击、邮箱点击、代码复制、图片放大、站内搜索（含命中数量）、主题切换、404 访问
  - 统计范围限定为线上域名，本地预览不再污染数据；同时清理了历史遗留的 655 条本地预览噪声记录（占当时总量的 40%）
  - 事件属性里的中文路径不再显示成 `%E9%9A%8F...` 这类百分号编码，可直接阅读
- 启用**会话回放与热图**：可回放匿名化的访客操作（仅记录交互事件、输入内容按规则打码），并聚合页面点击位置与滚动深度，用于判断长文哪一段读者会放弃；隐私说明已同步到统计页
- 自定义 **404 页面**生效：访问不存在的地址时显示站点自己的 404 页（此前是服务器默认页），同时计入统计
- 统计页卡片与站内其它卡片统一：加入入场动画与鼠标光效（按要求不含 3D 旋转）
- 修复：统计页各面板表格列宽不一致（主题的全局样式把表格重置成了块级元素）；本地预览点击站内链接会误跳到线上站点
- 服务器侧安全加固：敏感配置移入受权限保护的独立文件、管理端启用双因素认证
